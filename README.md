# RSNA Knee Abnormality Detection competition archive

This repository preserves the local notebooks, scripts, experiment notes, result archives, and model checkpoints from the completed competition work. The numbered notebooks and accompanying manifests document the experiment sequence. See `45_Final_Assessment_and_Selection.md` for the final assessment.

ZIP result archives and `.pt` checkpoints are stored with Git LFS. To restore the full archive after cloning, install Git LFS and run:

```bash
git lfs pull
```

Python bytecode caches and incomplete `.download` files are excluded from version control.
