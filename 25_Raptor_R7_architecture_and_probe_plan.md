# RSNA public 0.956/0.957 notebook audit — 2026-10-14

## What the supplied notebooks actually contain

The ten files are not ten independent architectures. `rsna-knee-abnormality-detection.ipynb` has the same scoring-code hash as `rsna-knee-0-956-raptor-convnext-r7-ensemble.ipynb`; `rsna-knee-fork-0957-heliosli.ipynb` has the same scoring-code hash as `rsna-knee-0-957-r7-blend.ipynb`. The latter 0.957 file has the same Raptor script, R7 bundle ID, inference controller call and stage-3 blend as the 0.956 file. Its material code difference is more permissive input-mount discovery. Therefore the two displayed titles/scores do **not** establish that a new architecture or changed weight improved 0.956 to 0.957.

The core two-engine recipe is:

1. Raptor: a CoAtNet `coatnet_rmlp_2_rw_384.sw_in12k_ft_in1k` multiple-instance attention model, 96 selected MRI slices at 384×384, one released SWA checkpoint. The file `raptor_ft_alldata_t16_blendjev_oai_d96_r384_swa.pt` is pinned to SHA-256 `7e5315dad125b99fc65b340b3de41de628e9be51ff5835355dd61c86472244ef` in the public source. Its training provenance includes OAI.
2. R7: a four-fold ConvNeXt-Small dense multi-view pipeline with knee-centred anatomical views, OA extent heads, synovitis decomposition, laterality correction and fluid/state stackers. The public bundle ID is `8c7b666e27dc0e8f`. It loads `rsna-knee-compact-r7cnxfsss` and `rsna-orthofoundation-fold0-epoch7-20261004`, verifies hashes and uses an offline wheel bundle. Some foundation/anatomy weights derive from external MRI datasets.
3. Each engine independently ranks its twelve predictions across successfully scored test studies; the final output is 50% Raptor rank plus 50% R7 rank for every target. The apparent per-class OA override is also 0.50, so it makes no numerical change. Failed studies can fall back to the other engine; the code tolerates up to 50% R7 failures, which must be examined rather than assumed harmless.

The distinct multi-scale variant in `rsna-knee-one-unused-checkpoint-lifts-the-0-956.ipynb` and `rsna-knee-multiscale-orthofoundation-sota-0-956.ipynb` adds `raptor_ft_alldata_t16_blendjev_oai_d96_c08_r224_swa.pt` (CoAtNet 224, 0.8 crop; SHA-256 `3394fdd7e668286956e85af2554bef0386df5cd79d1c1af223b095c828b815d6`). It gives this second Raptor checkpoint 35% of the original Raptor slot, yielding effective weights R7 50%, Raptor-384 32.5%, Raptor-224 17.5%. The public code may silently skip 224 when near the nine-hour limit; our 25B notebook refuses that fallback so the experiment remains identifiable. `rsna-knee-apex-grandmaster-v13-r7-superstack.ipynb` instead adds a tiny row-order-dependent anti-tie rank perturbation; that is not a new image architecture and is not included in the controlled first probe. `rsna-gold-medal.ipynb` is an older 0.950-era Raptor/ConvNeXt reader approach, not the R7 bundle.

## Limits that matter before a GPU run

The saved public notebook outputs contain only the three visible test studies. The two-engine source reports ~404 seconds total for those three, including ~330 seconds in R7 and ~51 seconds in Raptor. This is a functional smoke test, not evidence of hidden-test throughput or the asserted Public score. Kaggle's official code requirement is GPU notebook runtime at most nine hours, Internet disabled and `submission.csv` produced. The R7 code sets an 8.3-hour internal deadline. Scaling three-study time linearly to the hidden set is unreliable because startup, worker concurrency and DICOM variability dominate; run 25A first and inspect its hidden rerun status/receipt before 25B. Do not infer Private improvement from a Public gain alone.

The 24C 96×384 cache is competition-derived and for a separately trained CoAtNet experiment. It is **not** a replacement for the OAI-trained Raptor weights and is not consumed by R7 inference. Exact model reproduction relies on the released checkpoints and their full provenance. The host's OAI answer is conditional on the data being generally accessible without escalated institutional approval; we have not independently verified that the particular training sources and model licenses satisfy all winner-delivery obligations. A Public-LB experiment is not a final eligibility audit.
